# Netflix Data Cleaning and Preprocessing

## Objective
To clean and preprocess the Netflix Movies and TV Shows dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- VS Code
- GitHub

## Data Cleaning Operations
1. Identified missing values.
2. Standardized column names.
3. Cleaned inconsistent text values.
4. Removed duplicate records.
5. Handled missing values.
6. Converted date and numeric data types.
7. Removed rows with missing key values.

## Deliverables
- `data_cleaning.py` – Python cleaning script.
- `netflix_cleaned.csv` – Cleaned dataset.
- `cleaning_summary.txt` – Summary of cleaning operations.

## How to Run

Install Pandas:

```bash
pip install pandas
```

Run:

```bash
python data_cleaning.py
```
